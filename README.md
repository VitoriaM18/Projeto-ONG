# Projeto ONG Esperança

Projeto acadêmico desenvolvido para a criação de uma aplicação web para a ONG Esperança.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Funcionalidades

- Navegação entre páginas da aplicação
- Formulário de cadastro
- Validação dos dados
- Máscaras para CPF, telefone e CEP
- Armazenamento dos dados utilizando LocalStorage
- Layout responsivo

## Estrutura do projeto

- `html/` — arquivo principal da aplicação
- `css/` — estilos da aplicação
- `js/` — código JavaScript
- `img/` — imagens utilizadas no projeto
